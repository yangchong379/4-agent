# 02 设计、动态决策与取舍

CLI校验→模型inspect_request→search_materials→模型compose_script形成具体分镜→estimate_duration与check_rules返回实际结果→模型缩短停留/删镜/换表达并compose新版本→重新两项检查→finish输出完成或明确缺口。

不是只打印预写决策日志：真实接口每轮返回一个工具调用，工具执行后的实际观察回传下一轮。Mock为独立的确定性测试策略，只证明流程。检索空时可改写查询或停止；当前只支持合成剪辑/字幕主题和“文字上屏”别名，不将检索到的无关素材用于任意主题。

compose_script接受标题、visual、lines与hold_seconds；事实旁白必须逐字等于已检索source_id的事实，或从中性话语集合选取且不附事实ID。标题与画面选项有限，避免标题/画面绕过旁白规则编造能力。至少一条真实素材事实，禁止用全中性话语冒充产品脚本。服务端逐行验证，不把错误ID或80%等无来源陈述判为通过。

估时逐镜计算朗读字符数÷4（向上到0.1秒），与2秒最低镜长取较大值，再加显式停留；总时长是逐镜之和。目标只作为上限，没有保证靠近目标的优化器。不得靠任意提高语速骗过检查。新compose使旧时长/规则失效；finish只认可最新版本两份实际检查，无法靠模型文本声明完成。

持续工具失败保留已有稿件但返回tool_failed；两版未通过可constraints_unmet；未有足够证据finish会被拒并反馈模型。默认整个请求32步，协议拒绝也计入；模型或传输错误直接未完成，不隐式Mock兜底。

选择Python标准库原生循环，逻辑便于核查；无Agent框架。通用HTTPS调用协议、provider调用ID/必要内存reasoning回传及本机密码输入来自题2，业务工具/脚本状态独立实现，不跨目录依赖。限制是创作表达与事实格式受约束，不能宣称已实现自由文案的完整事实校验。接口参考[DeepSeek工具调用](https://api-docs.deepseek.com/guides/tool_calls/)。
